# FarmaTodo Elevate UI

Import and elevate the FarmaTodo Promotion Intelligence Studio frontend from frontend.zip into a settled, executive-grade UI (Linear/Stripe aesthetic) without changing underlying API contracts or hooks.

Key requirements:
1. Executive Visual Polish & Responsiveness: Keep existing palette and styling coherent, clean slate-50/100 surfaces, crisp borders, subtle shadows, and prevent horizontal blowouts with min-w-0 across desktop, tablet, and mobile.
2. Cluster Distribution Donut Chart in Campaign Studio sidebar: Interactive donut/pie chart with total audience in center, colored legend indicators, percentage shares, and hover tooltips.
3. Dose-Response Curve (ResponseCurve.tsx in Causal Deep-Dive): Smooth sigmoidal curve with shaded commercial zones (Dead Zone, Sweet Spot, Margin Burn Plateau), 90% confidence ribbon, dashed reference lines, interactive dose selector pills, and hover tooltip.
4. Cost Structure Bar: Multi-segmented progress bar in analytics and EconomicsCard with zero-division guards.
5. Purchase Cycle Timeline: Clean horizontal pill blocks for normal vs promo purchase cycles with blue highlights.
6. Cannibalization Flow & Waterfall: Polished directional substitution cards and 5-step causal waterfall protocol.
7. Cascading UnifiedFilterBar: Interactive selectors with category->SKU filtering, discount sliders with live badges, reset, and apply states.
8. Standalone Resiliency: Ensure all hooks gracefully fall back to rich realistic mock data so no charts or cards show blank, $0, or NaN% in preview.
